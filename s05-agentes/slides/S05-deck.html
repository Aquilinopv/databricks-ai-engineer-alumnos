Databricks AI Engineer · NeptunoS05 · Agentes

Glosario · bloque 2★

Tool call, dispatcher y span nombran piezas distintas

Tool call

Solicitud estructurada de ejecución emitida por el modelo.

Dispatcher

Código que valida el nombre y ejecuta la operación — como un enrutador, pero que además puede RECHAZAR (no solo dirigir).

Trace

Recorrido completo de UNA pregunta, de punta a punta.

Span

Cada paso individual DENTRO de esa traza, con su propia entrada/salida y duración.

Pregunta: "¿Cuál fue la venta neta de Bebidas en 2026?" → UN trace TRACE └─ span AGENT (predict) ─ recibe la pregunta completa ├─ span LLM "llm_tool_decision" (turno 1) │ → el modelo decide: tool_call { name: "ventas_categoria", args: {...} } ├─ span TOOL (ejecutar_herramienta) │ → el dispatcher valida (allowlist+schema) y ejecuta │ → devuelve {"venta_neta": 116024.88, "filas": 5, ...} └─ span LLM "llm_tool_decision" (turno 2) → el modelo redacta la respuesta final con ese resultado

Un span no es más que una fila con nombre, entrada, salida y duración — el trace es el árbol que agrupa todos los spans de una misma pregunta. Abrí esto en vivo en notebooks/02-agente-responsesagent-cp3.py, CP3.3.
